# Мебельное ателье

Статический сайт на HTML, CSS и JavaScript. Публичный контент и локальная обработка заявок используют app/js/site-config.js. Серверные функции заявок, метрик и рейтингов находятся в functions/api.

Запуск: python -m http.server 8082. Главная: http://localhost:8082/. Вход: http://localhost:8082/admin.html.

Авторизация: admin.html содержит форму, app/js/admin-login.js проверяет существующие логин и пароль и создаёт сессию; app/css/admin.css оформляет форму. Общий app/js/site-config.js сохраняет загрузку учётных данных из существующего хранилища. После входа открывается главная страница. Проверка учётных данных выполняется на стороне браузера.

Проверка синтаксиса: npm run check:js. Настройки публикации описаны в docs.
