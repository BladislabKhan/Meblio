# Hosting

## Подключение к любому обычному хостингу

Проект собран как статический сайт. Для запуска не нужны Node.js, npm, база данных или сборщик.

### Что нужно загрузить на хостинг

Загрузите в корень сайта всё содержимое папки `furniora-site`:

- `index.html`, `admin.html`
- папки `app`, `assets`, `functions`, `data`, `tools`
- служебные файлы `_headers`, `_redirects`, `robots.txt`, `sitemap.xml`, `.nojekyll`, `site.webmanifest`

### Важное правило

Не меняйте структуру папок после выгрузки. Все пути уже настроены относительно текущей структуры.

## Что работает на любом хостинге

- главная страница;
- стили, шрифты, изображения и анимации;
- вход по логину и паролю;
- локальные заявки;
- локальная аналитика;

## Что требует Cloudflare Pages

Следующие функции завязаны на серверные `functions/api/*`:

- защищённая серверная отправка заявок;
- общая серверная аналитика для всех посетителей;
- серверное получение рейтингов QR-блоков;
- Cloudflare Turnstile в полном режиме.

Если этих функций нет, сайт всё равно работает как статический проект и не ломается.

## Проверка после загрузки

1. Откройте главную страницу сайта.
2. Проверьте вход в `admin.html`.
3. Проверьте создание тестовой заявки.
